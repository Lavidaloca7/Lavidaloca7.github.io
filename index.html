Shorts Upload

A private upload tool for the YouTube channel WantedMoments.

What this app does

Shorts Upload is a small desktop script used by a single creator to publish their own short gameplay clips (recorded on their own PlayStation 5) to their own YouTube channel, WantedMoments, using the YouTube Data API v3.

  • It uploads videos created by the channel owner, with a title, description and tags written by the channel owner.
  • It reads the channel's own upload list to avoid duplicate uploads.
  • It is not offered to the public. There is no sign-up and no other users. It only accesses the channel owner's own YouTube account.
  • It does not access, collect or analyse data about other YouTube users or channels.

Google sign-in

The app uses Google OAuth 2.0 with the scopes needed to upload videos and read the channel's own video list. The access token is stored only on the owner's own computer and is never sent anywhere except to Google's APIs.

Deutsch

Shorts Upload ist ein privates Hilfsprogramm, mit dem der Betreiber des YouTube-Kanals WantedMoments eigene Gameplay-Shorts über die YouTube Data API auf den eigenen Kanal hochlädt. Es gibt keine weiteren Nutzer, und es werden keine Daten Dritter verarbeitet.
